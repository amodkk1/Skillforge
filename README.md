# SkillForge

Turn a short brief into a deep, expert-grade agent skill (`SKILL.md`).

**Live app:** https://amodkk1.github.io/Skillforge/

SkillForge runs a multi-step pipeline (deep analysis → architecture → full draft → expert review and rewrite loops) using your own Claude or Gemini API key, then lets you download `SKILL.md` or the whole skill folder as a `.zip`.

Your API key stays in your browser and is sent only to the AI provider you choose. Nothing is stored on this site.
